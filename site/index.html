ಎಲ್ಲಿದೆ — Kannada for “where is it?”

Install for Claude Desktop free · MIT

What you can ask

“What media files do I have on this Mac?”

8,910 files across sixteen places you had forgotten about — including the one you spelled wrong.

“Find the cycling event”

Finds it by what is in the picture, not what the file is called.

“Where did that clip go?”

On KERALA_2023. That drive isn’t plugged in.

How it works

  • It finds your media itself. No folder pickers, no paths. You don’t know where everything is — that’s the problem it exists to solve.
  • It reads what is already there. Dates, cameras, lenses, GPS, duration. Seconds, not hours, and no AI required.
  • Your own AI describes the rest. It hands pictures to Claude, and one description covers a whole shoot — a single caption can cover hundreds of files.
  • It never forgets. Rename or move a file and the index follows. Delete it and it still knows what you had, and which drive it was on.
  • Unplugged drives stay searchable. That is the whole point.

What it will not do

  • Upload anything. There is no server and no account.
  • Modify, move or rename a single one of your files.
  • Download your cloud files. iCloud and Dropbox placeholders are detected and left alone.
  • Put your private documents in a search index. An ID card or medical report is labelled by type only — never by its contents — and redacted if you export.

Free, MIT-licensed, and about 2,200 lines of plain JavaScript with no dependencies.
