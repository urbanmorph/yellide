How it works

It finds your media itself
No folder pickers, no paths. You don’t know where everything is — that’s the problem it exists to solve.
It reads what is already there
Dates, cameras, lenses, GPS, duration. Seconds, not hours, and no AI required.
Your own AI describes the rest
It hands pictures to Claude, and one description covers a whole shoot — a single caption can cover hundreds of files.
It never forgets
Rename or move a file and the index follows. Delete it and it still knows what you had, and which drive it was on.
Unplugged drives stay searchable
That is the whole point.

What it will not do

Upload anything
There is no server and no account, and the code makes no network calls.
Touch your files
It never modifies, moves, renames or deletes a single one of them.
Download your cloud files
iCloud and Dropbox placeholders are detected and stepped over.
Index your private documents
An ID card or medical report is labelled by type only — never by its contents — and redacted if you export.
